## 已实现的行为

每方300名士兵外加5名将领，每团最多60名士兵。将领固定600生命、20护甲、145速度、30伤害、190射程、0.6秒攻击间隔、600弹速，可展开和占点，不叠加自身士兵增益。军团标识锚定实际将领位置；隐藏敌将不显示。将领阵亡取消本团旧任务、手动命令、协同及排队指令；士兵沿合法路径回总部，仍可被攻击，不能进攻或占点。复活等待每10分钟增加10秒（开局10秒），死亡时锁定；将领复活且存活士兵完成回营后恢复控制。军团条显示将领生命、复活倒计时或等待回营。

装甲突击护甲15，其他基础数值不变。友方医院/区域卡使用蓝青色实线，敌方红色分段边界和三角警示，均有友/敌文字。估计战线与Alt+1入口移除；地图道路、目标和玩家路线保留。

普通撤退退到可见情报下的安全补给点：全团平均或突击/装甲加权组织低于35、兵力不足8、有限弹药低于15%或明显劣势触发。至少20秒休整、全团与前排组织均达到65、兵力达到撤退时75%且至少12人、恢复安全补给和所需弹药后才恢复。恢复点失守会重选目标；附近1200范围内组织至少35且未回营的友军计入支援兵力。暂停补员会使残部达不到恢复兵力门槛，这是玩家配额选择的后果。现行判定同时使用可调度分队组织平均值、突击与装甲按存活人数加权的前排组织（没有前排时退回全团值），具体数值与限制见 [五军团设计](archive/design/FIVE_LEGIONS_DESIGN_20260919.md)。

机动军团的新目标命令解除坚守/脱离；显式目标接近600范围且至少执行10秒前不被默认归位覆盖。拦截以受威胁高地为稳定目标，避免每2秒重建任务不断重置3秒准备。

## 找到并修复的根因

1. 持续补给点敌情的防守分支没有总是结束评估，下一轮又进入推进分支，造成固定往返。
2. 机动追踪敌方坐标过于频繁，准备尚未结束就被重置；移动目标没有同步解除坚守姿态。
3. 历史任务在决策与实时快照中反复复制；新兵分配扫描全军，攻击目标对明显更远的候选重复做昂贵校验。
4. 河岸无效侧向阵位导致反复导航；对称大地图为无效站位选择附近可通行空位。
5. 长线段每8坐标采样漏过细小拐角，实际短步却被地形拒绝。改为逐网格穿越检查，禁止切角。`hero24-bank-trace01.log`保留单位1035反复重寻的复现；修复后218项检查证明同坐标单位20秒前进3269.62，每步可通行，红蓝旋转路线一致。没有瞬移或穿障。

6. 长局发现突击兵组织0会被后方侦察/火炮组织100掩盖，平均组织仍允许推进。新增前排独立35/65撤退/恢复判断；mirror02（10000tick）与flank01（5000tick）因此中止，仅作诊断，不伪称整局完成。

7. 将领实体分配与大地图集火遍历改用稳定名称文本排序，避免StringName内部排序受资源加载影响。新增固定编号顺序检查；fire05保留为旧修订结果，fire06/flank02中断不算完整局。
