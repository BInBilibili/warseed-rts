# 同距离、固定观察窗的成长阶段追击验证

工作项`WS-MAINT-20260920-001`，legion44，B撤退战术补验。依据[此前动态追击](LEGION_PURSUIT_VALIDATION_20260924.md)已披露的两个混杂因素：12/60人撤离距离不同，将领死亡即停止导致不同终止时间的士兵数不能直接比较。正式legion43的695运行文件正在验收，保持冻结；本实验只新增隔离测试、证据及文档。

预注册输入：五军团×12/24/36/48/60人×发现敌军立即撤/停30tick撤×地图中心镜像，共100场。使用legion41受保护中间批次、真实upper_rear路线、既定候选数值与CombatSystem，同人数云岚编制持续合法追击，起始接触间隔192。所有规模队首从5000撤至1984，固定撤离3016；相应队尾目标均在实际道路内。固定观察600tick（60秒），将领死亡、达到出口或暂时脱离均不提前停止、不移除活单位、不抹除弹丸。

报告首次抵达/脱离/将领死亡时刻及第600tick双方存活、将领存活、敌方持续接触与弹丸、位置/伤害摘要；“安全脱离”必须有存活成员、全部存活成员到位且至少30tick无敌方可攻击目标和无敌方在途弹丸。将领阵亡单列，不能以残兵达到出口记为军团战术成功。记录无存活护卫的tick，补足此前仅计算有护卫时距离的观察盲区。

验收分层：速度、真实地块/路径、友军批间净空、中心间距、合法初始接触及实际追击开火等执行不变量必须通过；镜像及选定独立重复必须一致。战术结果原样保留，不新增“所有编制都须无损逃脱”的假门槛，不降低既定白九阳清点保留≥60%的门槛。本实验近距离强敌追击不是低风险清点验证。

先跑8场smoke（陆铮/林墨、12/60、立即/延迟、非镜像）检查夹具，随后100场矩阵；独立重复覆盖五团12/60两延迟，共20场。脚本与依赖运行前冻结，独立审计全字段镜像/重放、600tick时长和3016距离。场次、重复、逐tick断言分别计数，不宣称玩家胜率。

局限：仍是隔离执行器，没有正式世界完整视野遮挡、组织、成长补员、死亡回营/复活或交通命令管线；固定路径且没有接应、包围、动态截路及循环等候。共同队首撤离距离控制消除了路程差，编制构成、队列纵深和各批在地图的位置仍随人数改变，不能将差异全归因于人数。证据SIMULATED_PROTOTYPE，HUMAN/原生像素NOT_RUN，正式B/C/D尚未完成。

## 矩阵结果：中间成长阶段失守

matrix01会话15263实际退出0，100场执行不变量无失败，50对镜像所有字段（含归一化逐tick轨迹）一致；独立20场重放会话7433退出0且全部字段一致，独立审计回执为`artifacts/legion44/verification.json`。100场共136196466次逐tick/结构检查，不把断言数当战斗场数。原始结果与退出证据在`artifacts/legion44/matrix01.json`及`matrix-terminal.json`。

每格依次为“立即撤／停3秒撤”；数字为固定第600tick剩余士兵，**†表示将领已经阵亡**，无†表示该时刻满足脱离接触条件且将领存活。只列非镜像侧，另一侧一致。全部为同人数机动团近距离追击压力，不是对真人的胜率。

总计42场第600tick脱离、58场将领阵亡（包含镜像；独立战术输入为50组）。所有24/48人样本均失去将领；60人立即撤均剩49人，延迟云岚剩39人。不能由此定义“人数越多越安全”：角色比例、批次数、将领相对位置及沿路地形分布随人数改变，必须逐项拆分。

在所有100场中，将领存活时最近核心距离最大145.0571，没有“英雄活着但全无存活核心”的tick，仍有58场将领阵亡。因此“附近有护卫且距离≤240”不等于有有效掩护，不能以距离测试替代火力承受、目标选择和断后交接。

固定观察窗还区分了两个不同的结果：云岚36人延迟撤在tick208首次满足脱离条件，却在tick485将领阵亡；云岚60人延迟撤在早期曾到位仍接触，到tick366才真正暂时脱离，最终剩39人。此前legion41的“到位后仍接触10秒”只描述该终止窗口，不是永久不能脱离；同理3秒无敌火不是后续安全保证。新样本保留首次结果和固定60秒结果，不覆盖旧报告，也不合并成同一数据集。

## 后续设计处置

- 按全部五个成长阶段验证核心/将领/断后分配；优先查24、48人时的批次落点与敌方炮火/追兵接触，不通过调高将领血量掩盖未知原因。
- 将“脱离接触”作为可重新进入受威胁的动态状态；恢复整备还须检查出口接应、后队通过、合法已知追兵与在途火力，不将一次短暂停火永久锁定为安全。
- 林墨与白九阳的小编制需要可达断后位、提前风险退出或友军接应的单因素对照。当前仅3/12人存活的脱离也不能称低损撤退，白九阳低损清点原门槛不变。
- 本轮只验证统一3016距离，不能外推更长撤退、包围、截路或循环堵塞。正式legion43自然局另外暴露远距离换护卫，两个问题分别记录：一个是隔离阵位战斗保护不足，一个是实际执行长局脱队。
