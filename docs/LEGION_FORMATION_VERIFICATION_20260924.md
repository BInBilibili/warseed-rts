## 2. 行军脱队的原因和修正

仅让将领追逐安全槽仍不足以实现固定军团。原卡队形锚点可按180推进，而狄天、林墨将领速度为150；即使目标槽到护卫≤240，运动中的将领也未必能追上。当前护卫选择修正为优先附近真实主力、旧护卫超过240可更换，但这不能替代全团队速协调。

本轮候选在测试用MovementHook内，将本团AI控制卡的锚点速度上限设为将领与必需同行成员当前速度的最小值（非侦察、已归队、非回营；上限不超过旧180）。单位基础数值、战斗参数、路径、命令和玩家控制权不改。侦察不决定核心队速；该候选仍不是完整独立先导/批次执行器，不能外推其战斗侦察效率。士兵按原真实移动系统归位，不瞬移；本轮严格速度断言针对将领，不宣称已新增全体士兵碰撞/超速验收。

## 4. 自然局事件重放失败

600tick诊断首次在361tick复现蓝红两张侦察卡的TACTICAL_ACTION_COMPLETED顺序交换，随后441/541tick也发生完成/中断事件交换。相关`TacticalAbilitySystem`的卡ID使用StringName内部排序。测试替身将advance、cancel_for_order、update_identification三处改为明确文本顺序后，两次600tick各1311事件完全一致；保留原系统失败记录。这尚不能证明整场长局所有差异都仅是上述顺序，也没有正式修复生产。

下一正式修复应保持稳定文本排序，按权威系统变更补回归、完整门和自然长局；不能通过排序最终日志或忽略事件序列来让失败变绿。详细经济数据见[自然局报告](LEGION_NATURAL_ECONOMY_20260924.md)。
