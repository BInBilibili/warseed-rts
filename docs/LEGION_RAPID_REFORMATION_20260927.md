## 1. 授权、目标与适用范围

用户本次明确允许：阵型恢复、窄路恢复和变阵期间短暂无视单位碰撞与单位体积，代价为受到伤害 ×1.5；空间受限时允许缩小间距；玩家直接指挥移动时需要阵型空间范围指示。本文把“伤害 ×1.5 倍速”解释为**承受的生命伤害提高 50%**，不是敌人攻速、游戏时间或我方移动速度变为 1.5 倍。

目标是缩短内部互相让路造成的重整耗时，让玩家仍只决定整团/整卡的目标、方向和风险。正常行军、正面封锁、地形绕行仍有战术价值，不以穿透方式代替整张大地图的交通系统。五将固定兵种配比、逐人成长与补给表继续沿用；本轮不增加可手选兵种或二十个阵型按钮。

## 2. 无碰撞的精确边界

采用“快速重整”临时执行状态。建议首版只豁免友军间移动碰撞；敌军保持封锁作用，防止借重整直穿敌阵或包围圈。该友军限定是本次设计取舍，并非声称用户已逐项指定。

| 对象或约束 | 快速重整时规则 |
|---|---|
| 本团士兵、将领之间 | 获准重整成员可穿过友军身体，关闭该碰撞对的排斥、推挤和最小移动间距；固定身份不交换 |
| 其他友军 | 可在获准局部重整区穿过其身体，不推走对方；结束槽仍扣除对方实体、已承诺阵位和通行带。不能利用此规则完成两支窄路相向大军对穿 |
| 被玩家停止的友军 | 不移动停止单位；可以局部经过其身体，不能把它的最终占位当空位。没有合法结束槽就不启动 |
| 敌军 | 保留敌我碰撞、近身阻挡与包围，不用快速重整穿越敌占通道。隐藏敌造成的受阻仅返回普通过路失败，不泄露位置/身份 |
| 地形、建筑、地图边界 | 不豁免；每段运动保留实际地形包络，当前候选 64（边界各 32）。不足一人地形包络的口不因重整可走 |
| 弹丸、锁定、受击、视野 | 保持原规则与受击体积；单位仍可被选择、锁定、命中和杀死，不隐身、不无敌 |
| 最终停靠 | 必须有不重叠的实体落脚位；允许行进交叉，不允许重叠驻守、占点或架炮宣称成阵 |
| 通道预约 | 仍保留正在通过批次间的 96 净空、最多 12 实体/批及方向锁；穿透不释放物理未清空的通道 |

“忽略体积”只针对上述友军移动碰撞计算；不缩放模型、受击半径和地形半径，不删除空间索引中的单位。进入状态的士兵和将领都承担 ×1.5 伤害；未参与重整的警戒成员正常承伤。远处新兵沿真实路线归队，不获得跨地图穿透或追赶加速。

## 3. 承伤、攻击和伤害时序

生命伤害在既有随机、武器修正、护甲和其他合法减伤结算后，仅乘一次 `1.5`，再扣当前生命。现有普通命中基线为 `D = max(1, 攻击力 − 护甲)`；若按原规则这次没有生命伤害，则仍为 0。例：50 攻击对 14 护甲，普通 36，重整 54；10 攻击对 14 护甲，普通 1，重整 1.5。保留浮点生命，不额外按整数向上取整；过量伤害后的实际损失不超过剩余生命。

以**命中结算 tick**的受害者状态决定倍率：进入前发出的弹丸在重整中命中也乘 1.5，重整后才命中则按普通状态。多枚命中逐次正常结算；事件记录普通伤害、倍率、最终伤害及实际生命损失，不再对最终损失重复乘 1.5。

不加速攻击冷却、流血计时、恢复计时、组织下降或经济时间。纯压制不新增生命伤害；既有非炮车伤亡组织影响仍按实际损失走原管线。最终决战炮车继续只造成生命伤害，不因该倍率恢复已取消的组织压制。治疗不放大，自毁/将领死亡整团回营等非伤害指令不经这个乘区。

参与者可按现有武器规则自卫，不额外赠送移动射击、命中率、射程或战力光环。炮车实际移动会打断驻停展开，仍需重新连续驻停 20 tick；仅状态名称变化且车辆没有移动时，不无故重置已有武器准备。未到合法非重叠炮位不能借重整重叠开火。压缩成阵本身不持续施加 1.5 倍惩罚，惩罚来自重整/未分离状态。

## 4. 状态、时限与失败退出

行动仍是进攻/移动/防御/撤退；快速重整是执行子状态，压缩档位是空间属性，控制归属另存。不能把“开始变阵”“进入宽路”或“命令入队”写成任务完成。

| 状态 | 行为与退出 |
|---|---|
| 普通执行 | 使用当前稳定阵型/纵列；微小位置误差正常补位，不自动增加伤害风险 |
| 重整规划 | 确定受影响成员、稳定槽位、局部合法路径、完整落脚容量和退回槽；规划失败直接保持现状/压缩/等候，无穿透和额外承伤 |
| 快速重整 | 仅获准成员豁免友军移动碰撞，承伤 ×1.5；目标 30 tick 内完成，单次硬上限 60 tick，其中最后 10 tick 预留给终止与落脚 |
| 成阵观察 | 成员实际到位并已恢复碰撞，连续 20 tick 检查当前档位就绪；单位各自安全落脚后即解除承伤惩罚，不为整团观察期延长惩罚 |
| 分离待恢复 | 意外阻挡/停止/超时使个别单位仍与友军重叠：关闭穿透许可，恢复对新碰撞的阻挡，只允许降低既有重叠的普通速度移动；这些重叠成员继续 ×1.5，直到真实分离 |
| 空间不足/受阻 | 保留原意图和未完成回执；普通碰撞下等候、沿已授权路线重规划或撤退，不循环开穿透试错 |

进入须同时满足：需要实际换位；参与成员可控且属于该意图；有合法结束阵位；按当前地形速度估算能在最多 50 tick 内到位；将领及同批护卫有共同可达方案。无需换位的稳定前线不跟着进入；普通≤6单位偏差只做日常修正。不能用无碰撞弥补数千距离脱队。

默认触发：动作改变引起交叉换位、窄口前收列、尾队清口后的展开、局部战损/补员恢复，以及内部让路连续 10 tick 无净进展且重整方案可行。普通行进和每 tick 朝向微调不触发；方向稳定期仍为 20 tick。有效撤退可立即改变目标，但不要求先原地旋转全团再撤。

以单位为粒度结算状态/承伤，以本团一次重整计划保持稳定成员和阵位；同一单位任意 100 tick 内的穿透许可累计不超过 60 tick，结束后至少 30 tick 才能重新获准。换动作、重复点击、D-036 自动交还、重规划或变更意图版本均不清空预算。撤退/死亡回营不会被冷却拦住，只在无可用穿透预算时按普通运动执行。新兵不重置老成员预算。

入场前预留不重叠结束槽，重整区域为“起点至已分配结束槽的局部合法路径包络”，不扩展到整条战略道路。每 tick 按稳定身份顺序复核剩余路径、预留和时间；预计无法完成即提前停止新成员进入，先落脚或返回仍可达的预留槽。原退回槽与结束槽也不能重复承诺给其他军团。

玩家停止立即停止目标推进，不以“必须成阵”为由继续移动。若此刻已重叠，进入分离待恢复、保留 1.5 倍风险并明确显示；停止单位不被自动推开，待有效移动命令后再按普通速度分离。不可永久保留自由穿透以等空间，也不可瞬移或一帧超速推开。10 tick 未分离显示卡上异常，30 tick 后合并告警；这种动态失败必须留在模拟结果中。

将领死亡立即终止旧重整意图并进入现行整团回营，活成员的重叠债务/承伤不因换任务凭空消失。已死实体解除自己的预约，其他身份不重新编号。伤亡、护卫失效、新敌封锁、玩家改令均需重新核验；安全退出失败就报告失败，不强行恢复“完整阵型”标签。

## 5. 自适应压缩：保留角色而非全团缩放

采用“标准 → 轻压缩 → 紧凑 → 减列/分批 → 受阻”的有界顺序。压缩只作用于同角色组的局部间距/排数，不把将领保护、炮组前卫间隔、敌我距离、道路边缘余量一起乘比例。损失成员留下稳定身份空位，可由邻近同职责成员有界补位，不重排全团编号。此前 legion37 全局压紧的负结果仍适用，不能因新穿透直接宣称已解决战损风险。

| 形态 | 首版候选中心间距 | 限制与用途 |
|---|---|---|
| 标准 | 48 | 正常空间优先保持；大地图常态默认 |
| 轻压缩 | 普通成员 40 | 边缘地形、友军预约或局部障碍导致标准槽无解时采用 |
| 紧凑 | 普通成员 32 | 轻压缩无解时用于局部部署；不把单位画小，不增加攻击加成 |
| 炮车涉及的阵位对 | 至少 48 | 炮车—炮车、炮车—其他成员都保留至少 48；真实尺寸若更大取更大值 |
| 将领/护卫关系 | 保留各团 128/160/192 保护设计和 ≤240 可达护卫上限 | 不把全局后置距离压至 2/3；无可用核心按残阵规则退出 |
| 分组关系 | 林墨前卫与炮组约 128–192 等职责距离保留 | 仅压缩组内密度；不足时改变组形/分批，不将炮车挤到前卫前面 |

所有静止实体仍需满足实际非穿透间距。当前候选物理下限 24；若未来任何兵种真实尺寸要求更大，最终安全间距取更大值。**32 槽间距与每人 6 的到位容差不能直接并用**：两人向内各偏 6 只剩 20。对槽距 `s`、要求实际间距 `d` 的相邻对，到位容差上限为 `min(6, (s−d)/2)`；32/24 对应每人最多 4，并且最终还要检查真实成对距离。友军穿透只豁免重整过程，不豁免结束校验。

以普通成员直列及两侧各 32 地形余量算：8列在48/40/32间距下宽度分别400/344/288。288虽小于320，**不代表野区可改成8列常态通行**：弯道、混合炮车、将领保护、批次与出口容量仍可能无解；野区默认3列、河道4列、主路8列继续作为交通上限，压缩用于部署和局部换位。3列标准包络160、4列208均保留。实际槽位包络不一定是矩形，更不能用统一缩放推导所有五团面积。

选择方案时在玩家接受的目标范围内保持朝向/职责，依序检验标准、轻压缩、紧凑；同档多个方案按偏离原目标最小、位移最小和稳定ID破平。宽度不足优先减列增纵深；纵深不足可加宽减排，但不超实际空间和该交通上限；两向不足才分批使用独立容纳区。通过能力、当前成阵与整团到达分别报告。

稳定压缩态可持续作战，不每 tick 尝试扩张。恢复更宽档须所需实际包络连续可用 20 tick，预估任务收益成立且有重整预算；逐档恢复，受火时优先保持已有可用火线。部署点局部扩张以目标空间检查为准；从窄路切回行军宽阵仍需前方连续640路径的相应包络可行。后队未清空时不向中央通道横铺。

## 6. 三路、野区、窄路出口和五团差异

主路名义1024、河道512、野区连接320；小平台768×768、大平台1280×1024。它们是地图资源尺寸，不是可全部占用的空地。建筑、边界、既有友军、预约、当前实员（含将领）及96通行带都需扣除。地图坐标用中心180°旋转镜像验算，不用左右反射替代实际对称。

窄路出口顺序：本批获得侧方合法落脚容量 → 实际越过采样窄口 → 局部快速重整进入预留侧位 → 全批地形包络清口且不再占中央带 → 释放本批出口占用 → 后批进入。已清口批次按当前参与者先形成可用警戒阵，不能横穿仍在通过的后批路线。将领和真实护卫共同通过，后卫未到不拖动已展开炮组。

最后一批清口后，按原动作/目标恢复完整或压缩角色阵型。**本次队列中央带**可在全团实际清空后解除；**仍被其他友军预约、公共交汇要求保留的96通道**不能解除。原目标被其他合法预约占据时采用压缩/同目标范围内修正/等候，不能为了通过断言删除预约。旧“所有角色永久不得靠近原通道”的限制不再适用；也不能一律删除所有通行净空。

出口物理完成、部署完成、任务完成分开：尾队真实清口可发 `EXIT_CLEAR`；所选标准/压缩阵位真实到位、解除穿透且稳定20tick才发 `FORMATION_READY`（附档位与参与人数）；在原接受目标范围满足命令语义后才发任务到达。全团仅到暂存侧位或仅部分兵到位不能发完整到达。清口之后实际回流进通道须重新取得许可，旧清口回执不是永久通行证。

| 军团 | 重整重点 | 压缩后必须保留 |
|---|---|---|
| 陆铮 spear | 浅楔与纵列之间由两翼局部换位，稳定先导先警戒 | 装甲在突破方向，突击跟进；空间不足改浅楔/混合列，不让将领先穿到敌前 |
| 狄天 guardian | 前后层局部换位，优先保持已接敌的一层 | 双层互保；紧凑可加深队形，不因成阵追求暂停整条防线 |
| 林墨 gunner | 前卫与炮组分阶段重整，已开火炮组尽量保持 | 炮位间距、前卫隔离和重新驻停；25门炮无空间就部分部署，不能重叠炮车换取全体开火 |
| 白九阳 sentinel | 收回观察组、恢复侧后位，只让返回成员承担风险 | 武装侦察占点资格不变，窄路先导仍最多2名；已见强敌前不为整齐强行回收穿阵 |
| 云岚 ranger | 救援落脚后快速建立保护核心和接敌前沿 | 不占受援方撤离带；局部就绪可报接替能力，不能只凭全团穿透抵达就通知原守军离场 |

四态原则：进攻先取得落脚空间再变阵；移动只在入窄口/出窄口/必要转形时重整；防御只调整受影响区域；撤退立即沿退路走，边走边局部恢复，不为漂亮阵型原地等待。不可达地形、敌方封锁、丢失护卫和出口满员需要各自原因码，不能一律用压缩掩盖。

## 7. 玩家移动的空间指示

选中兵团或正式可控整卡并准备移动时，在指针目标显示地面部署预览。单卡手控仅显示该卡实际接受控制的成员包络；整团命令包含当前已归队可执行成员和将领，远处新兵以独立归队提示呈现，不用满编60人的固定圆代替真实队伍。多团同时命令需给各团分配独立落点，不能复用同一空地。

预览包括：标准角色阵型虚线轮廓、当前可行方案实线轮廓、稀疏阵位点、朝向箭头、将领/炮组标记和必要通行带缺口。包络由所有实际槽位地形余量的并集求出，外框只帮助阅读；不能仅以外框宽高判断凹地形可放。大地图常态只显示所选队伍及目标附近信息，避免恢复已移除的全地图战线覆盖层。

| 指示 | 含义及示例文案 |
|---|---|
| 绿色实线＋“完整” | 标准阵型可部署；显示宽×深与实际人数 |
| 黄色实线＋“压缩” | “可压缩部署：间距40”或“紧凑32”；旁边保留标准虚线供比较 |
| 橙色纵列＋“只能通行” | 点可到但宽阵无法部署；“将在出口展开”，给出首个已知可用出口轮廓，找不到则注明空间不足 |
| 红色斜线＋“无法部署” | 地形/预约/出口容量无解；区别“路径不可达”和“可到达但无法展开” |
| 灰色虚线＋“待确认” | 未知动态占用尚未确认；仅公共地形可行，不显示隐藏敌人轮廓或安全保证 |

颜色配文字/形状，中英本地化，不能只靠红绿区别。已见威胁下给“重整期间承伤+50%”标记；重整启动后卡上显示“快速重整：参与人数/总数、剩余时间”，将领参与时单独提示。仅显示玩家能合法知道的威胁，未知区域不当成无敌。

普通点击按现有规则给方向和目标，朝向默认路径末段；可用已有拖动输入指定落点朝向，不新增强制操作。点无完整空间但允许压缩时直接接受所示压缩方案，无弹窗；单纯移动到可通行窄点允许纵列到达，但不得显示已恢复战斗阵型。攻击/占领/防御仍分别验任务射界、范围、通行和资格，不能拿纵列移动完成代替它们。

轻微修正候选锚点最多偏移96，且须同一可达连通区域、相同任务/占领区域，预览显示原点击点到实际建议点的连线。已经选定可行压缩方案时，不擅自跳到96以外追求宽阵。超范围建议只显示备用轮廓，玩家另点才改变目标；不能静默转到道路另一侧或另一个据点。

点击提交“原点击目标、预览建议目标、朝向、意图版本与允许自动压缩”的统一命令。权威层重新校验：容量已变则在同一允许范围找下一档/等候并给原因；不得把预览的乐观结果强行应用。受限于迷雾而无法确认的占用显示一般受阻，不回传隐蔽实体信息。UI只读值快照，不直接改位置。

保持D-036接敌3秒/非接敌10秒自动交还。重整不刷新接管时钟、不抢回玩家停止卡、不要求玩家逐兵整理。AI接手继续当前合法目标和重整预算；AI与玩家共享空间评估和碰撞规则，AI只用本阵营合法知识。
