# 移动回退与将领脱队修复

工作项 WS-MAINT-20260920-001 / motion29，2026-09-21。用户报告单位移动“一进一退”，以及野区军团将领停在高地、远离部队。本轮只修已有移动/随军行为；新玩家与 AI 控制规则写入独立[设计稿](PLAYER_AI_CONTROL_RULES_DRAFT_20260921.md)，尚未开发。

## 根因与修复

### 1. 后台模拟派发时显示时间提前回退

宿主从累计时间中扣除0.1秒后把下一逻辑步交给后台线程，此时上一对快照仍在显示。原插值直接使用扣减后的累计时间，导致同一对快照插值从0.99退到0.01，单位与弹道反复重播旧位置。这是显示时钟错误，不能靠增加模拟频率或降低画质解决。

现在尚未发布的后台步骤所占0.1秒仍计入显示插值；已发布位置范围之外不外推，新快照收集后才切换区间。未改10Hz、权威位置、命令队列或线程独占边界。较慢步骤仍可能造成短暂停住，但同一对已发布快照不会因派发而倒放。

### 2. 将领寻路到不可通行的全团平均位置

旧逻辑将所有非侦察存活士兵的位置取算术平均。队伍绕地形或有远处补员时，这个平均点不一定可站立。真实地图复现：士兵在(21264,7760)和(22032,7760)附近，平均点(21648,7760)位于障碍；将领在(21264,8400)反复没有路径。修复前日志motion29-repro-before02确认，修复后可取得到实际成员位置的合法路径。

现在候选来自本军团实际存活成员，优先640范围内较集中的主力，按距全团中心与稳定实体ID打破平局。每秒最多尝试8个不同网格的路径；散出的侦察不干扰普通主力，有且仅有侦察时跟随侦察队，无士兵才尝试战略目标。到达96范围且直连可通行后驻停，不跨河隔墙提前判定归队。

路径失败会重试，仍合法的旧路径保留；新障碍使旧路径无效时停止，记录HERO_FOLLOW_UNREACHABLE。候选与寻路仅使用本方成员及既有地形，无隐藏敌情读取，不瞬移或提高将领145移速。地图绕行、兵种速度差和玩家分兵仍可能产生暂时距离，不能保证任意配置始终重叠。

### 3. 独立交战逻辑覆盖将领随军路径

将领原本也进入普通单体的局部追击/返回逻辑，其旧交火原点可能与移动主力相距很远。现在将领仍选择合法射程内目标并开火，移动由军团随军逻辑负责，不再独自追敌后返回旧原点。保留坚守、死亡回营和复活的既有硬规则，不改变士兵的局部追击规则。
