# 终局决战操纵权限执行契约

决策：D-040（2026-10-04，产品负责人本次明确授权）。工作项：WS-MAINT-20261004-001。仅用于最终决战 growth_mode；旧四关、v4档案、10Hz、合法知识、D-037阵亡回营与D-039显式阵型继续有效。原权限草案是设计来源，本契约决定本切片的执行语义。

## 权限与优先级

1. 世界硬约束：终局、死亡回营、所属阵营、存活实体、合法目标/视野、路径和实际战斗限制。
2. 同范围最新有效玩家命令：固定按 issued_tick、命令优先级、command_id 顺序应用；撤退与强攻没有永久高低，后者覆盖前者。应用前拒绝的命令不抢走旧权限。
3. 仍有效的将领持续意图与整卡接管：AI只能执行授权目标。将领新命令覆盖本团所有旧持续意图与整卡微操；整卡命令只影响本卡。
4. 已批准协同：只控制未被玩家抢占的范围。后续阶段和排队AI命令必须复验授权版本；显式交还不恢复已取消的图阶段。
5. 自主战略与合法局部战术：不能靠后台刷新恢复撤销的权利。

命令入队保存值副本和作用范围版本，不提前更改目标、位置或手控状态。模拟tick先复验玩家命令的合法性，再使本批有效玩家命令涉及的旧AI授权失效；统一应用入口检查版本和硬规则。过期战术及图阶段产生AUTHORITY_STALE回执；原有自动目标/支援抢占保留既有拒绝原因。UI使用合法值快照区分接受待执行与实际执行。

## 将领级意图

| 模式 | 玩家锁定 | AI权限 | 结束与交接 |
|---|---|---|---|
| 指定目标 | 目标区域及途经路线 | 原目标内战术；按现有条件临时安全恢复，恢复后返回同一目标/路线 | 到达/占领后保持；替换、取消、交还或硬规则中断 |
| 强攻 | 目标与必须进攻的执行方式 | 合法绕障、局部射击与炮位调整；低组织/伤亡只提示风险 | 禁止自主整团撤退和战略改向；达成后保持 |
| 坚守 | 各卡当前防区 | 防区内自卫、补位与合法补给 | 持续到替换/取消/交还 |
| 有序撤退 | 撤离到合法安全区域 | 合法路径脱离与沿途自卫 | 不反向追敌、不插入旧进攻；到达保持 |
| AI自主 | 解除全团玩家意图 | 按当前合法情报重新评估 | 不复活旧玩家目标、恢复路线或协同阶段 |

强攻期间地图转移目标默认保留强攻。显式选择平衡/谨慎/进攻姿态恢复普通目标及AI战术恢复权；“进攻姿态”本身不等于强攻。取消命令切换各卡当前位置坚守，同时撤销本团卡接管与旧计划；只有“交还全团AI”恢复自主。无指定点的撤退复用既有合法撤离推荐；typed目标命令可显式请求RETREAT并指定点，使用同一导航校验，菜单撤退使用推荐点。参谋显式撤退解析真实图内军团范围，按玩家命令顺序撤销旧阶段并发逐团回执。

路线最初非法则拒绝并保留旧命令。已经接受的任务途中受阻保留玩家目标，沿用既有30tick受阻重试，侦察不能另选探索区；实际不可行动者不能恢复生命、穿障或读取隐藏敌情。强攻不改变组织硬限制和武器/速度规则。
