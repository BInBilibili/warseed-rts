# 玩家与将领 AI 操纵权限设计稿

状态：**历史设计来源**。2026-10-04产品负责人授权新工作项[WS-MAINT-20261004-001](work_items/WS-MAINT-20261004-001.md)，D-040及[终局决战执行契约](PLAYER_AI_CONTROL_CONTRACT_20261004.md)将持续意图、整卡接管、撤退、取消和显式交还转为正式规则。下文保留原提案及当时实现问题；“尚未开发”、3秒/10秒交还及未来建议不得覆盖正式契约。原WS-MAINT-20260920-001其他范围仍REWORK。

## 1. 目标与当前问题

玩家负责“打哪里、是否必须执行、何时停止”，将领负责“在授权范围内怎样执行”。玩家必须能看出当前由谁掌握目标、AI 能否撤退或改道、怎样重新接管，避免刚下命令就被 AI 默默改写。

2026-09-21提案时，整卡微操在接敌约3秒、非接敌约10秒无新命令后自动交还，且不存在“强攻锁定”。这些历史问题已由D-040取代：强攻是独立持续意图，普通进攻姿态仍不等于强攻，整卡不再计时交还。当前事实见[现行玩法](CURRENT_GAMEPLAY.md)及正式执行契约；与固定编制的关系见[兵团提案](LEGION_GAMEPLAY_PROPOSAL_20260921.md)。

建议将持续战略指令和临时微操明确区分。持续指令不因玩家几秒钟没有操作而消失；选择单位、查看信息、移动镜头也不改变指挥权。

## 2. 权限与操作范围

|对象|玩家决定|AI 可决定|AI 不可擅自决定|
|---|---|---|---|
|军团|战略目标、执行模式、撤退/坚守、交还自主权、参与协同|合法路线、队形、分队衔接、授权范围内战术|用默认任务覆盖有效玩家目标，私自结束强攻，分走军团将领|
|部队卡|临时移动、集火、停止、回到军团任务|授权后的补位、射击、局部避障|临时接管期间另下移动命令，因鼠标离开就抢回控制|
|战区资源|补员配额、预算、支援卡投放、协同批准|在既有预算内执行已授权事项|擅自花费未授权战区支援、调整玩家配额|
|将领实体|随所属军团行动；通过军团指令间接控制|靠近本团主力，在射程内交战|为追击单个敌人离开军团、向无路平均点永久寻路|

正式操作粒度仍是军团和整张部队卡，不增加逐士兵微操。侦察分队可按任务前出；它的远出不应把将领和其他主力拉走。玩家刻意把多张卡派往不同方向时，UI 应提示“军团已分散”，将领随主要战斗群，不瞬移，也不暗中撤销玩家分兵。

## 3. 指令模式

|指令|玩家锁定的内容|AI 可以做什么|AI 不可以做什么|结束/交接|
|---|---|---|---|---|
|**强攻**|选定军团、目标区域或方向、必须进攻的意图|沿可通行路线推进；队形展开、开火、装填；在同一进攻方向内避障和短距离战术调整|因谨慎性格、低组织、局部劣势或其他据点告急而自行换目标、整团撤退或回默认防区|玩家取消、替换或明确交还；达成目标后原地控制并报告，等待下一命令；死亡回营等硬规则可中断|
|**转移目标**|新的战略目标点；覆盖本团旧战略目标|选择路线、安排侦察、支援和兵种展开；普通目标模式可临时安全恢复，强攻模式仍保持强攻限制|擅自把目标改成另一据点；恢复后遗忘玩家目标；把路过补给点当作任务完成|目标完成后保持目标区并报告；玩家替换、取消或交还|
|**有序撤退**|撤退意图及选定安全区域；无指定点时请求 AI 推荐合法点|脱离接触、寻找撤离路径、沿途自卫、到达后恢复|途中反向追敌、把自动进攻任务重新插入队列|到达并恢复后保持，提示可重新部署；玩家可显式下达新命令，死亡回营硬锁除外|
|**坚守**|当前或指定防区|防区内展开、开火、补位；授权范围内补给|离开防区抢点、远追、默认回防替换防区|保持到玩家替换/取消/交还|
|**卡牌临时微操**|选中卡的眼前移动/攻击/停止动作|其他未接管卡继续原任务；被接管卡仍能合法自动射击|用军团后台命令覆盖该卡的有效微操|明确完成条件或玩家交还；详见第5节|
|**交还 AI**|主动解除指定范围的玩家意图锁|重新评估合法情报、自主目标和安全恢复|恢复已经取消的旧玩家命令或过期协同任务|UI 明确显示“AI 自主”；下一条有效玩家指令可再次接管|

### 强攻的精确定义

“完全按照玩家要求进攻”表示 **AI 没有战略改向或自主整团撤退权**。玩家指定的是方向/目标和执行意图，合法路径可以绕过山体与河流，并非要求所有单位沿直线穿越障碍。

低组织、伤亡和劣势只产生风险提示，不自动撤销强攻。无法行动的单位仍服从实际战斗规则：死亡、眩晕/组织限制（若既有规则适用）、火炮展开/冷却、路径不可达、非法目标、战斗结束不能被强攻绕过。不能为了执行强攻而恢复生命、改变速度、获取隐藏敌情或强制穿障。

强攻允许 AI 在目标方向上选择可见敌人的射击目标；该射击选择不等于获得新战略目标权。遇到不可达目标时停在最后安全可达位置，持续自卫并报告“路线阻塞”，保留强攻意图，按有界频率重试；不能假装成功，也不能自行换一个据点。

### 转移目标与强攻的差别

“转移目标”规定目的地，保留 AI 在现有规则下临时撤退恢复的权利；恢复后必须回到同一个玩家目标。“强攻”同时锁定进攻执行方式，禁止此类自主整团撤退。

切换目标时默认保留当前模式。例如强攻 A 时选择“转移目标至 B”，结果应是“强攻 B”，不能悄悄降成自主模式。UI 在确认前显示将生效的模式。玩家可显式选择“转移目标并恢复 AI 战术判断”，它才解除强攻锁。

方向型强攻须落成一个地图内的目标区域/路线终点，不接受无限期朝地图外走的隐含语义。夺取据点以该据点的实际完成条件判断；攻击空地区域以主力到达并完成展开判断。射击单位目标丢失视野时仅使用最后合法已知位置，不追踪隐藏真坐标。

## 4. 优先级与同一时间的冲突

从高到低：

1. **世界硬约束**：战斗已结束、单位死亡、将领阵亡后的整团回营锁、实体/阵营权限、合法知识和路径校验。
2. **玩家最新有效意图**：在相同操作范围内覆盖旧玩家意图，包括强攻、撤退、目标转移、坚守、取消和交还。
3. **仍有效的玩家持续意图及临时卡牌接管**：AI 只能在其许可范围内执行。
4. **已批准的协同方案**：仅调度未被玩家新意图抢占的军团/卡牌。
5. **将领自主战略和局部战术**：遵循上层限制，不能用后台刷新重新取得已撤销授权。

撤退和强攻都是玩家意图，**后接受的有效命令覆盖先前命令**；不能让历史撤退永久挡住玩家的新强攻，也不能让旧强攻压过刚下达的撤退。只有死亡回营等硬约束仍不可覆盖。

范围规则：军团新指令明确覆盖本团旧持续意图及正在执行的卡牌临时微操，确认预览应列出受影响卡；卡牌指令只接管该卡，其他卡继续军团任务。一次操作作用于多个军团时，逐团返回结果；部分拒绝必须明确显示，不能用一个“成功”掩盖失败成员。

未来实现建议使用 **指令 ID、作用范围、意图版本和发行顺序** 做确定性仲裁。接受新意图时使同范围旧 AI 计划、排队命令和未触发阶段失效；应用时再次校验版本。已被拒绝的玩家命令不改变当前权限，已执行的历史 tick 不回滚。同 tick 相同范围多条玩家命令按统一命令管线的稳定顺序确定最后有效意图，不依赖 UI 帧率或线程完成顺序。

## 5. 临时微操与交还

建议将当前“持续行军也会超时交还”的行为改为动作明确结束后再交接；**此条尚未开发，当前游戏仍沿用原计时规则**。

|临时动作|建议结束条件|结束后|
|---|---|---|
|移动|到达并展开；玩家取消；明确路径失败|提示“已到达/受阻”，允许一键回到军团任务；不在途中计时抢回|
|指定集火|目标消灭、失去合法目标或玩家取消|先自卫并报告；不能悄悄追击另一个远处目标|
|停止|保持停止意图直到替换或交还|“停止”不自动等价于3秒后继续旧行军|
|短时修正|玩家明确选择“临时修正”时才使用计时授权|面板显示剩余时间，模拟暂停时不走表，有效新指令续期|

卡牌交还时：若军团仍有强攻/指定目标，则归入该意图；若军团自主，则归将领 AI。卡牌级交还不会解除整个军团的玩家意图锁。旧路线/旧敌人目标不直接重放，应根据当前合法情报重新接入有效任务。

## 6. 操作焦点、界面与回执

**选择焦点、命令模式和执行权限必须分别显示。** 选择其他军团或移动镜头不会取消此前命令；点击将领头像只选择/定位，不产生接管；双击定位、框选、悬停、键盘翻页均不发送战术命令。

建议军团条常显：`玩家·强攻 → 西侧高地`、`玩家目标·AI执行 → 中路补给点`、`玩家·坚守`、`AI自主`、`将领阵亡·回营中`。临时手控卡另有标记，不用整团一个颜色掩盖混合授权。

操作流程建议：选择军团 → 点击“强攻/转移目标/撤退” → 地图预览目标、路线和影响范围 → 确认。Esc/右键取消未确认的瞄准模式，**不取消已执行命令**；取消当前命令需要明确按钮。“取消命令”默认转为当前位置坚守，只有“交还 AI”才恢复自主，避免用户本想停下却又看到军团自行开走。

回执分为 `已提交`、`已接受待执行`、`执行中`、`受阻`、`目标达成`、`已取消/被替换`、`被硬规则中断`、`已交还`。入队不冒充执行成功。失败须显示具体原因，例如“目标不可达”“将领阵亡，正在回营”“目标已不可见”；同时保留有效旧指令，除非它本身已经失效。

AI 只能发出建议：“当前强攻风险高，建议撤退”，并提供撤退按钮；强攻期间建议不是命令。相同原因的提示合并并冷却，避免刷屏。面板说明“为什么停下”和“谁拥有目标权”，比反复弹出泛泛警告更重要。

## 7. 关键场景及预期

|场景|预期行为|
|---|---|
|强攻中损失过半|提示风险；仍向玩家目标执行，不自动改守另一高地；无法行动者保留实际限制|
|强攻 A 后转移目标到 B|停止 A 的后续阶段，沿合法路线强攻 B；旧 AI 下一帧不得把 A 写回来|
|指定目标途中组织不足|普通指定目标可临时恢复，面板保留目标；强攻不因该策略判断整团撤退|
|强攻时玩家命令撤退|新的有效撤退立即取得意图权；旧强攻和关联协同队列失效|
|微操一张炮卡，其他卡继续战斗|只接管炮卡；将领不另改炮卡移动；其余军团任务继续|
|在微操尚未到达时切换镜头|微操不因此失效；切回仍看到任务和权限状态|
|将领阵亡|既有死亡回营硬规则生效，旧强攻中断并报告；复活后不自动重放|
|部队质心位于河道、道路暂堵|将领走可达随军路线，不向不可达质心无限失败；堵路显示原因，恢复后重试|
|玩家取消瞄准但未下新指令|仅退出当前输入模式，现有战场命令不变|
|敌人进入迷雾|AI 不跟踪隐藏坐标；按合法最后位置/区域处理并报告目标状态|
|AI 和玩家同 tick 下令|玩家新有效意图胜出；旧 AI 命令应用时明确拒绝，不出现一进一退|
|异步模拟较慢|显示等待执行状态；不提前改写权威位置，不回退已显示的同一快照区间|

## 8. 后续实现边界与验收

未来开发须先把本提案确认成正式决策，再按最小切片实现：typed 意图/权限数据 → 统一校验与队列仲裁 → 将领/卡牌执行 → 合法快照与 UI 回执 → 测试及存档兼容评估。不得仅加一个 UI 按钮而让后台继续覆盖玩家意图。

至少覆盖：同 tick 排序与过期指令拒绝、拒绝不抢权、作用范围隔离、协同取消、接管/交还循环、暂停/再战、不同线程耗时下事件一致、隐藏目标、强攻低组织边界、死亡回营、双语及五档分辨率。若未来增加意图持久化，须先明确存档范围和迁移；本轮不改 v4。

本稿采用的默认建议是：持续战略意图不超时、强攻不自主整团撤退、目标达成后保持、取消转坚守、交还才恢复自主。以上均供后续审阅修改；**本次没有实现这些新的控制规则**。
