# WARSEED 自主交战修复版 · 2026-09-19

> 历史归档：正文只描述当时版本，旧“当前/下一步/待验证”不再授权执行。现行规则与进展从[文档入口](../../README.md)读取。

运行同目录 `WARSEED.exe`，保留 `WARSEED.pck`。地图为32,768×24,576，南北野区串联河道，双方48人起步、上限256。

本版修复大地图交战：侦察可以协同射击；炮车普通攻击自动识别、停稳后开火；将领集火与玩家移动路线独立；无将领也可自主攻击，停止时短追并回位；死亡领车即时替换。

普通移动仍按玩家路线走，火力车仍需停车2秒展开。炮车普通弹当前只压制组织度，不造成生命伤害；区域导弹轰炸才造成180伤害。完整兵种、经济、战法、AI差异和规划规则见 **CURRENT_NUMBERS_AND_TACTICS_20260919.md**。

补员按固定模拟秒最多5人，每团0～2，最低储备可配置；跨秒两批和10秒新兵绿圈可能造成短时“超过5人”的观感。配额、人口和费用专项结果见 **COMBAT_AUTONOMY_VERIFICATION_20260919.md**。

玩家给将领战略目标后，该将领保持目标，不自动选择下一点；归还整卡不等于恢复军团战略自主。红方自动区域支援、蓝方手动支援的差异仍保留并在文档中说明。

操作：滚轮缩放，中键/WASD移镜头，小地图点击定位，空格暂停；普通整卡移动到达稳定2秒后可自动归还AI，明确接管/停止维持手控，R交还。左侧补员方案设置配额/储备，右侧比较完整军团战术方案。
