# WARSEED 五军团战略指挥版

> 历史归档：正文只描述当时版本，旧“当前/下一步/待验证”不再授权执行。现行规则与进展从[文档入口](../../README.md)读取。

运行同目录 `WARSEED.exe`，选择独立对局“最终决战·裂谷三线”。旧交付目录保留。

战前配置上、中、下、野、机五军团：每团四兵种目标合计60，可将某兵种设为0；五位将领各任一团，选中已任职将领会交换任职。滚动到编成页下方可设置接敌/无敌情自动交接时间，默认3/10秒。每团12人开局，自动按计划扩充至60，全军上限300。

玩家指定战略方向、路线、协同进攻/互援与补给预算，将领执行侦察、编队、集火、炮火和补员。机动军团默认守高地，依据合法敌情阻击；也可手动指定支援方向。右键微操后没有新指令会自动交回将领，R可立即交回。空格暂停。

下方显示五军团兵力与组织，展开分队可查实际兵种数值。悬停将领、兵种、补给点和支援卡查看增益、武器和经济参数。小地图/远景显示上中下野机；黄圈为敌情，红圈为受击，配有限频提示音。导弹卡3秒命中；导弹车展开有支撑脚、准备圆弧及发射架形态变化。

每秒全军最多补充5人，默认五团各1人；优先军团2人、三团各1人、机动暂停（机动优先则暂停野区）。可自定0–2配额和最低补给储备，给战术卡留预算。侦察基础速度200，详细数值见 `../design/FIVE_LEGIONS_DESIGN_20260919.md`。

加载已加入后台构造与进度条，但首次场景切换仍可能短暂停顿。600人密集持续交火压力测试仍有明显卡顿；本版不能视为性能问题已解决。测量、验收与不牺牲表现的后续优化路线见 `../reports/FIVE_LEGIONS_VERIFICATION_20260919.md`。

最终决战历史独立保存，每局重置战场兵力与装备；再战可沿用并修改上一局编成。自定义兵种容量与旧v4历史兼容；损坏文件不会被空档覆盖。测试证据为SIMULATED，不代表真人体验或胜率平衡结论。
