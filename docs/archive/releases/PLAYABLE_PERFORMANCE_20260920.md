# WARSEED 五军团·将领与撤退修订版

> 历史归档：正文只描述当时版本，旧“当前/下一步/待验证”不再授权执行。现行规则与进展从[文档入口](../../README.md)读取。

双击 WARSEED.exe，选择“大地图对战 / 最终决战”。战前配置上、中、下、野、机五军团，每团最多60名士兵，并各有1名独立将领。将领不可重复任职；战中自动补员，全军每固定秒最多5人，可设置各团配额与补给储备。

本版新增将领实体，军团标识跟随将领。将领阵亡即取消全团旧指令，士兵回总部；将领复活且存活士兵回营后才能重新受令。将领复活每10分钟增加10秒，开局10秒。军团条显示将领血量、复活倒计时或“等待回营”。装甲突击护甲调整为15。

敌我医院和区域卡有不同颜色、边界样式及友敌文字。估计战线已移除。新方向命令可解除坚守/脱离，机动军团不再因反复重建拦截任务而停滞。普通撤退退守安全补给点，至少休整20秒，达到组织度、兵力和安全补给要求后恢复。

空格键战术暂停；小地图显示上/中/下/野/机和敌情警告。详细数值与卡片条件在游戏内悬停中查看。玩法与数值见 FIVE_LEGIONS_DESIGN_20260919.md；数据模拟、性能改善与剩余问题见 COMMANDER_REWORK_20260920.md。

本轮按要求仅进行无窗口SIMULATED验证，没有实机试玩或帧率验收。610实体压力场景的模拟P95由219.939ms降至86.013ms，最大单步119.274ms，首次战术方案冷构造约6.17秒，不能承诺密集战斗已经流畅。最终两种策略局分别8分43.4秒与12分27.9秒蓝败，尚未验证稳定蓝胜或20–40分钟节奏目标。旧版独立包保留；存档v4兼容，不需要删除现有存档。
